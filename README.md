# 족보 오리자보어 — 족보 재검증 도구

의대 **족보**(선배들이 모아 둔 과거 시험문제·해설 모음) PDF를 넣으면, AI가 문제를 하나씩
다시 풀어 **답과 해설을 재검증**한 뒤, 보기 좋게 정리된 **워드 문서(.docx)** 와
**웹 뷰어(.html)** 두 가지를 만들어 줍니다. 코딩 지식은 필요 없습니다.

내가 시험 공부하려고 만들어서 쓰던 도구를 그대로 묶은 것입니다. 편하게 쓰세요.

---

## 이 도구가 해 주는 일

1. **문제 추출** — 족보 PDF에서 문제·보기·정답 표시를 자동으로 뽑아냅니다.
2. **사람 확인 단계** — 추출이 제대로 됐는지(문항 수, 미리보기)를 보여 주고, 여러분이
   "예"라고 확인해야 다음으로 넘어갑니다. 이상하게 뽑혔으면 설정을 바꿔 다시 시도합니다.
3. **블라인드 재검증** — AI가 원래 답을 **미리 보지 않고** 문제만 보고 스스로 풀어 본 다음,
   원본 답과 비교해서 맞음·정정·애매함을 표시하고 새 해설을 답니다.
   (원본 답을 먼저 보여 주면 AI가 거기에 끌려가서 검증이 안 되기 때문입니다.)
4. **결과물 생성** — 정리된 워드 문서와, 인터넷 없이 열리는 웹 뷰어를 만듭니다.

### 웹 뷰어에 들어 있는 것

- **학습 모드 / 시험 모드** (시험 모드는 제한시간 타이머)
- 범위 · 연도 · 교수별 **필터**, 문항 **셔플**, 정보 **가리기**
- 🚩 **체크 표시**, 진도·정답률 **자동 저장**(브라우저에 저장 — 껐다 켜도 유지)
- 문항 검색, 이미지 확대, 키보드 단축키
- 파일 하나짜리 HTML이라 **더블클릭만 하면 열립니다.** 서버·인터넷 불필요, 폰으로도 열림.

> **솔직한 안내:** 재검증을 실제로 하는 건 AI라서 **틀릴 수 있습니다.** 특히 수치·기준·약물명은
> 그럴듯하게 지어낼 때가 있어요. 시험 공부에 쓸 때는 강의록·원본과 꼭 같이 보세요.
> 이 도구가 보장하는 건 "정답"이 아니라 **한 번 더 의심해 보는 절차**입니다.

## 준비물 — AI 코딩 도구 하나

이 도구는 **"AI에게 말로 시키면 컴퓨터 작업을 대신 해 주는 프로그램"** 안에서 돌아갑니다.
평소에 쓰는 AI에 맞춰 **딱 하나만** 설치하면 됩니다:

| 평소 쓰는 AI | 설치할 것 |
|---|---|
| **ChatGPT** (오픈AI) | **Codex** |
| **Gemini** (구글) | **Antigravity** |
| **Claude** (앤트로픽) | **Claude Code** |

셋 중 아무거나 **하나만** 있으면 되고, 모르겠으면 제일 익숙한 걸로 고르세요.
설치 방법은 해당 회사 공식 사이트의 "시작하기" 안내를 그대로 따라 하면 됩니다.

파이썬 같은 나머지 프로그램 설치는 **AI가 알아서 합니다.** 직접 명령어 칠 일 없습니다.
(윈도우·맥 둘 다 됩니다.)

## 사용법

1. 이 폴더의 **압축을 풉니다.**
2. 설치한 AI 도구를 켜고, 방금 **압축을 푼 폴더를 엽니다.**
   (막히면 아래 〈폴더 여는 법〉 참고)
3. 내 과목 **족보 PDF 파일**을 이 폴더 안에 넣습니다.
4. AI에게 이 한마디만 입력하세요:

   > **"README.md 읽고, 내 과목 족보 PDF로 시작해줘"**

5. 그 다음은 AI가 설치 → 추출 → 재검증 → 문서 만들기를 진행합니다.
   중간에 **"이 추출 결과가 맞나요?"** 하고 물으면, 보여 준 내용을 확인하고 **"예"** 라고 답하세요.
6. 다 끝나면 **`output/` 폴더**에 워드 문서와 웹 뷰어가 생깁니다.

### 시간이 얼마나 걸리나 — 먼저 읽으세요

**한 과목을 끝내는 데 며칠 걸립니다.** 앉은 자리에서 끝나는 작업이 아닙니다.

| 단계 | 대략 |
|---|---|
| 설치 (처음 한 번) | 10~30분. 인터넷 필요 |
| PDF 추출 | 1~5분 |
| **재검증** | **여기가 전부입니다.** 문항 하나에 1~2분씩, 200문항이면 몇 시간 |
| 문서·뷰어 만들기 | 1~3분 |

재검증은 AI가 문제를 **하나씩 실제로 풀고 해설을 쓰는** 단계입니다. 족보 한 권이 보통
200~600문항이니, AI 사용량 한도에 걸려 중간에 멈추는 게 정상입니다.

**그래서 이렇게 쓰세요:**

- 시험 **2~3주 전에 시작**하세요. 전날 밤에 시작하면 못 끝냅니다.
- 한 번에 다 하려 하지 말고, **하루에 한 단원씩** 끊어서 하세요.
- 멈추면 다음에 AI에게 **"이어서 해줘"** 라고만 하면 됩니다. 중간 결과가
  `output/<과목>_work/` 에 남아 있어서 처음부터 다시 하지 않습니다.
- 급하면 AI에게 **"시험 범위인 ○○ 단원만 먼저 해줘"** 라고 하세요.

무료 요금제로는 사실상 어렵습니다. 유료 구독(월 20달러 수준) 하나는 있어야 합니다.

### 〈폴더 여는 법〉 — 처음이라면

"폴더를 연다"는 건 AI 도구에게 **"이 폴더 안에서 작업해"** 하고 위치를 정해 주는 것입니다.

- **Antigravity 같은 '편집기형':** **"Open Folder"(폴더 열기)** 메뉴에서 압축 푼 폴더를 고릅니다.
- **Claude Code · Codex 같은 '명령창형':** 압축 푼 폴더를 **터미널**에서 연 다음 도구를 실행하면
  그 폴더가 작업 폴더가 됩니다.

제일 쉬운 방법은 — **도구를 일단 켜고 AI에게 그대로 물어보는 것**입니다.
*"방금 압축 푼 이 폴더에서 작업하고 싶은데 어떻게 열어?"* 라고 하면 알려 줍니다.

## 잘 안 될 때

거의 다 **AI에게 그대로 말하면 해결**됩니다. 상황별로 이렇게 말해 보세요:

| 상황 | AI에게 할 말 |
|---|---|
| 문항이 너무 적게/많게 뽑힘 | **"추출이 이상해. `--auto-format` 붙여서 다시 뽑아줘"** |
| 문제 앞에 앞 문제 해설이 딸려 옴 | 위와 같음 (`--auto-format` 이 이런 걸 잡아 줍니다) |
| 문항이 아예 0개 | 스캔 PDF(글자가 아니라 사진)일 수 있음 → **"OCR 먼저 해줘"** |
| 위 방법으로도 추출이 지저분함 | **"Segmenter 써서 다시 뽑아줘"** (AI가 문서를 한 줄씩 분류해 다시 자릅니다 — 좀 더 걸립니다) |
| 중간에 멈춤 | **"이어서 해줘"** (중간 결과가 저장되어 있습니다) |
| 뭔가 에러가 뜸 | 뜬 화면을 **그대로 복사해서 붙여넣기** |

## AI가 내부적으로 하는 일

AI가 따르는 자세한 동작 규칙(실행 명령, 블라인드 재검증 순서, 문제 해결)은
[CLAUDE.md](CLAUDE.md) · [AGENTS.md](AGENTS.md) 에 있습니다 — **사람은 열어 볼 필요 없습니다.**
(도구마다 읽는 파일 이름이 달라서 같은 내용을 두 이름으로 넣어 뒀습니다.)

궁금하면 AI에게 *"너 지금 뭐 하고 있는 거야?"* 라고 물어보면 한국어로 설명해 줍니다.

## 자료 이용 및 개인정보 안내

**꼭 읽어 주세요.** 이 도구는 여러분이 넣은 자료를 다루고, 그 일부가 외부 AI 서비스로 나갑니다.

### 이 저장소에 들어 있는 것

이 저장소에는 **도구 코드와 자체 작성한 테스트용 가상 예시만** 포함되어 있으며, 실제 시험·족보 원문은 포함하지 않습니다.
코드의 MIT 라이선스([LICENSE](LICENSE))는 **입력 자료나 그 내용을 담은 산출물에 대한 이용·재배포 권한을 부여하지 않습니다.**

### 어디까지 외부로 나가나

완성된 HTML 뷰어는 오프라인으로 사용할 수 있습니다. 다만 **외부 AI를 이용한 재검증 과정에서 에이전트가 읽는 텍스트·이미지·도구 출력은 선택한 AI 서비스로 전송될 수 있습니다.**
데이터의 보관 및 모델 개선 사용 여부는 해당 서비스와 계정 설정에 따릅니다.

### 무엇을 넣어도 되나

**적법하게 이용할 수 있고, 필요한 외부 서비스 처리까지 허용되는 자료만 사용하세요.**
환자·학생 등 실제 개인을 식별할 수 있는 정보나, 외부 제공이 허용되지 않은 자료는 입력하지 마세요.

### 결과물을 다룰 때

산출물·진도 백업·오류 화면에도 **원문이나 개인정보가 포함될 수 있습니다.**
이를 공개 저장소나 공개 이슈에 올리지 말고, 오류 신고에는 **자체 작성한 가상 예시**를 사용하세요.

족보와 결과물은 개인 학습용으로만 쓰세요. 단톡방·클라우드 공유 링크도 공개와 다르지 않습니다.
